# MaxCV

> 노력 없이 완성하는 완벽한 이력서 스튜디오

[maxcv.pages.dev](https://maxcv.pages.dev)

---

### 주요 특징

- **한국어 폰트 20종**: 프리텐다드, 마루부리 등 고딕·명조 무료 웹폰트 기본 제공
- **정밀 조판**: 이름, 직무, 섹션 본문별 글자 크기(px), 줄간격, 자간 미세 조절
- **자유로운 레이아웃**: 이름·직무 배치(1줄/2줄), 항목별 좌·중·우 독립 정렬, 구분 기호 설정
- **클라우드 보관**: Google 로그인 기반 계정별 자동 저장
- **벡터 PDF 인쇄**: 텍스트 복사와 링크 클릭이 유지되는 깔끔한 A4 인쇄

---
